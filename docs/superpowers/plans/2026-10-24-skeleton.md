# Skeleton (Component 0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local server that boots: Fastify + SQLite with the full schema, a health route, and a guarantee that the API key header is never logged.

**Architecture:** One npm package. `src/server` runs under `tsx` (Fastify on `127.0.0.1:3001`, database at `data/maptutor.db`). Tests run under Vitest in Node. The frontend (`src/client`) is added in component 8.

**Tech Stack:** Node 24, TypeScript 7, Fastify 5, `node:sqlite`, Vitest 5, tsx.

**Spec:** [README.md](../../../README.md), [04-data-model.md](../../../04-data-model.md), [05-stack.md](../../../05-stack.md#byok), [ROADMAP.md](../../../ROADMAP.md)

## Global Constraints

- Node ≥ 24. The `ExperimentalWarning: SQLite is an experimental feature` line at startup and in test output is expected.
- IDs are text UUIDs (`crypto.randomUUID()`). Timestamps are integer milliseconds (`Date.now()`).
- Single implicit user, with `id = 'local'`.
- The API key travels in the `x-anthropic-key` request header. It is never stored server-side and never logged.
- The server binds `127.0.0.1` only.
- All server routes live under `/api`.
- Work on branch `component-0-skeleton`.

## Review Focus

1. **Server restarted on an existing DB file.** It should hit no "table already exists" error and should not add a duplicate user row. Test in Task 1.
2. **Project deleted.** Its files and studies should go with it, which only happens if foreign keys are actually enforced. Test in Task 1.
3. **Request carries a key.** The key must not appear anywhere in the server log output. Test in Task 2.
4. **Server started from a clean checkout.** The `data/` folder doesn't exist yet. The server should create it instead of failing. Checked in Task 2, Step 6.

- [ ] **Step 1: Install**

Run: `npm i fastify`

- [ ] **Step 2: Write the failing tests** in `src/server/app.test.ts`

```ts
test('health check answers ok', async () => {
  const res = await buildApp(openDb(':memory:')).inject('/api/health')
  expect(res.statusCode).toBe(200)
  expect(res.json()).toEqual({ ok: true })
})

test('never logs the API key', async () => {
  const lines: string[] = []
  const app = buildApp(openDb(':memory:'), { write: l => { lines.push(l) } })
  await app.inject({ url: '/api/health', headers: { 'x-anthropic-key': 'sk-ant-secret-123' } })
  expect(lines.length).toBeGreaterThan(0)
  expect(lines.join('')).not.toContain('sk-ant-secret-123')
})
```
