# Polish (Component 11) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The usage popover on both screens, the goal-complete card and its confetti burst, and the design doc's "Doc updates" list.

**Architecture:** Pure figures in `lib/format.ts` (model names, rounded token counts, totals), tested with Vitest. `components/Usage.tsx` is a top bar button with a popover over the `usage` arrays the study and project endpoints already return. `pages/Goal.tsx` shows the goal-complete card in the goal node's thread once the phase is `done`, and fires `components/Confetti.tsx` when it sees `teach → done` live. No new dependencies.

**Tech Stack:** React 19, Web Animations API, Vitest, `playwright-core` screenshots against `dev:fake`.

**Spec:** [docs/superpowers/specs/2026-10-25-frontend-design.md](../specs/2026-10-25-frontend-design.md): Usage popover, Goal complete (map and card), Doc updates

## Global Constraints

- Popover: `surface`, radius 14px, popover shadow, under its button like the API key panel; closes on an outside click or Escape.
- Tokens only, no money. Confetti colors: the four state fills and `accent`.
- Reduced motion: no confetti; the card still shows.
- Commits carry no Claude attribution.

## Rulings

- **Popover layout** follows `usage.html` option B (the spec's text): title 15px 800, headline 28px 800, "N web searches" muted under it, then one block per model with a divider, its name in 800 and a two-column grid of muted labels and tabular figures. Width 300px (the mockup's 380px fit a table; B is a narrow grid).
- **Figures:** under 1,000 exact (`611`); then one decimal with `k` (`48.2k`); from 999,950 two decimals with `M` (`1.20M`). The headline is `<figure> tokens`.
- **Per-model rows:** Input, Output, Cached (read + write) always; Searches only when non-zero (the spec's text over the mockup, which dropped a zero Cached).
- **Searches line:** always shown, "1 web search" / "N web searches".
- **No usage yet:** "0 tokens", "0 web searches", no model blocks.
- **Model names:** `claude-<family>-<major>-<minor>` with an optional date suffix → "Family major.minor"; anything else as-is.
- **Projects screen:** the Usage button shows only while a project is open (the first-run screen has none).
- **Goal-complete card:** at the end of the goal node's thread while the phase is `done`, hidden while a turn streams so it stays after the tutor's last message. "Goal complete", "N of M known", and the mastery bar of all nodes (full green when every node is known, which the spec's example shows).
- **Confetti:** only on a `teach → done` change seen in the open page (never on load); 80 pieces burst upward from the goal circle and fall under gravity over ≈1.8s, then the layer unmounts.
